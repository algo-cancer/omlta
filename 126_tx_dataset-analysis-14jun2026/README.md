 This is a description for files related to the analyses presented in our work on the 126 metastatic cases of non-small cell lung cancer (nsclc) originally published by [Al Bakir et al. 2023](https://www.nature.com/articles/s41586-023-05783-5). For each case in this dataset, we first constructed multiple, alternative clonal trees using PairTree. Then, using <i>omlta</i>, aligned the highest posterior probability tree to its corresponding trees previously inferred by the use of CONIPHER. Further, we used the histological subtype annotations to compare the robustness of trees between 57 LUng ADenocarcimona (LUAD) and 38 LUng Squamous Cell carcinoma (LUSC); additionally, we identified mutation labels (as gene labels) that were frequently deleted (between CONIPHER and PairTree solutions for the same case) across cases within the same subtype.

<b>data/</b> (folder)<b>:</b>\
This folder contains three files ("20221109_TRACERx421_all_patient_df.rds", "fullTreeOutputList.RDS" and "mutTableAll.cloneInfo.20220726.txt") which were retrieved from [10.5281/zenodo.7649257](https://zenodo.org/records/7649257). These files were not generated as part of this work. These files are read as input in the notebook "ncomms_25_48701AZ-tx_dataset.ipynb" for the experimental results presented in our manuscript.  
- "20221109_TRACERx421_all_patient_df.rds" contains the histological subtype annotations for each of the 126 metastatic cases in the non-small cell lung cancer cohort.

- "fullTreeOutputList.RDS" contains the tree topologies inferred by CONIPHER (released in the original study by Al Bakir et al. 2023); for each case/patient, there is exactly one CONIPHER tree corresponding to the tree with the best objective. 

- "mutTableAll.cloneInfo.20220726.txt" contains somatic mutation calls, e.g., mutational loci, nucleotide character state change, cluster (clone) assignment and the mutational frequency (for each sample, given as "PhyloCCFs"). We used these same mutational clusterings and cluster frequency values from the original study as input to PairTree to build alternative clonal trees for alignment in our work.

<b>resources/annotations/</b> (folder)<b>:</b>\
This folder contains two files ("Cosmic_CancerGeneCensus_v102_GRCh38.tsv" and "cancerGeneList.tsv") which are from two cancer gene censuses, [Catalogue Of Somatic Mutations In Cancer (COSMIC)](https://cancer.sanger.ac.uk/cosmic) and [OncoKB](https://www.oncokb.org/cancer-genes). These files were not generated as part of this work. We use the same version of the reference assembly as that used for somatic mutations calling in the original study to get the gene labels. Primarily, these resources were together used to discriminate mutations occurring in genes with (and without) a putative role in cancer; in the above listed order of files, the related column names are "ROLE_IN_CANCER" and "Gene Type".

<b>tree-alignment/</b> (folder)<b>:</b>\
This folder contains 126 folders, each corresponding to a metastatic case/patient in the non-small-cell lung cancer dataset, files have the naming convention "[cruk_case_id]/" (ex., "CRUK0003/"). Within each of these folders are two subfolders, named "conipher/" and "pairtree/". The "conipher/" folder has one text file which contains the tree previously inferred by CONIPHER in the original study. The "pairtree/" folder has ten text files which each contain a solution inferred by PairTree; these files are indexed, from 0 to 9, in descending order of the posterior probability of the tree. In the parent file, again for example in "CRUK0003/", there are two text files. One file, ex. "CRUK0003.pairtree-soln_8.aligned.formatted.tsv", contains the omlta alignment tree. The other file, ex. "edit_sequence_CRUK0003.txt", contains the sequence of edit operations (i.e., node expansion and deletion, and label deletions) for both input trees to achieve tree isomorphism. In "tree-alignment/", for each case, we provide the alignment tree and sequence of edits between the CONIPHER and PairTree tree that minimizes the omltd (within the top-10 solutions ranked by posterior probability). In the folder "vm/tree-alignment/", we provide the alignments between the CONIPHER tree and the PairTree tree with the highest posterior probability. All trees are saved as text files in a tab-separated format with columns "node_id", "parent_id" and "mutations". "parent_id" is the parent of "node_id", which is labeled by "mutations".

<b>ncomms_25_48701AZ-tx_dataset.ipynb</b> (file)<b>:</b>\
This file contains a Jupyter notebook for analyses performed for the 126 metastatic cases of nsclc presented in our work, specifically those related to comparing between LUAD and LUSC subtypes.
